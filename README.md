## 一、这个项目是什么

**Hytera（海能达）以顾问身份，向菲律宾运营商 Globe Telecom 提交的 450MHz 频段利用方案。**

| 项 | 内容 |
|---|---|
| 客户 | Globe Telecom（菲律宾最大移动运营商之一） |
| 受众 | Globe **VP 高层**，**初次技术交流**性质，不是投标 |
| 前提 | Globe **已持有 450MHz 频谱**，但不知道怎么用；本方案回答"怎么用" |
| 品牌 | **方案甲：保留海能达品牌外观**（用户已确认），不做白牌 |
| 主线 | 450MHz 不是容量层，是**覆盖与韧性层**；先由付费能力最强的行业客户锚定需求，再由运营商建一张网 |
| 交付形态 | 英文 PPT（22 页）+ 逐页英文演讲稿（写进 PPT 备注）+ 中文说明文档 |

## 三、给接手 AI 的关键提示

### 3.1 怎么改这个 PPT

**不要手改 PPTX。** 改 `03_生成脚本/build_ph450m_v7.py` 然后重跑：

```powershell
# 1) 重新构建（整篇重建）
python build_ph450m_v7.py <模板.pptx> <输出.pptx>

# 2) 必须补这一步——重跑构建会清空全部备注
python ppt_notes.py 菲律宾450M讲稿_v7.md <输出.pptx>

# 3) 版面检查（只看 error 数，warn 多为误报）
python ppt_check.py <输出.pptx> --quiet
```

### 3.2 脚本里的两个坑

1. **模板的 `notesMaster` 没有占位符**，python-pptx 因此建不出备注文本框。脚本已在保存前注入 `body` 占位符；**换模板要重新确认这一条**。
2. **保留模板页再加页会让 python-pptx 复用同名 part**，写出重名 zip 条目导致文件打不开。脚本已改为清空全部模板页后重建。

### 3.3 图片处理的两个坑（都踩过）

1. **透明底 PNG 不能走 JPEG 合成**。脚本里 `slim()` 会把 RGBA 合成白底，所以透明图必须走 `keepalpha()`——`fit()` 已改用它。搞错的话图标全变白方块。
2. **超大图要先缩**。脚本里 `slim()` 限 1600px、`keepalpha()` 限 900px，否则 PPTX 会涨到 40MB+。

### 3.4 设计规则（用户反复强调过的）

- **配色**：白底 `FFFFFF` + 卡片 `EEF2F9` + 海能达蓝 `0B308E` + 橄榄绿 `7F9B00` + 亮绿 `8CC63F`。**不要做成深色**（做过一版被否）。
- **每个元素都要说明一件事**。用户明确否掉过：底部拼贴横带、白底图标方块、漂浮装饰插画、无意义的天线塔图标。
- **导览页用插画，细节页用实拍**（用户明确要求）。
- **配图必须图文相关**。用户是逐张看图挑错的，放"意义不明"的图一定会被指出。

### 关于三个案例与 450MHz 的关系

**三个案例在原始资料中都不是 450MHz 部署**：
- **斯里兰卡铁路**：原文写 "utilizes public network resources LTE"；唯一关联是 Alliance 确认 **Dialog 持有斯里兰卡 450MHz 牌照**
- **香港轻铁**：明写 "MCS over 5G"，香港无 450MHz 划分
- **巴新警察**：ICC 指挥中心；Alliance 表里巴新 450MHz 状态是 "Available"（未分配）

**真正的 450MHz 案例在 P15**（德国 450connect、奥地利 ArgoNET、马来 TNB 等）。
