## 一、这个项目是什么

**Hytera（海能达）以顾问身份，向菲律宾运营商 Globe Telecom 提交的 450MHz 频段利用方案。**

| 项 | 内容 |
|---|---|
| 客户 | Globe Telecom（菲律宾最大移动运营商之一） |
| 受众 | Globe **VP 高层**，**初次技术交流**性质，不是投标 |
| 前提 | Globe **已持有 450MHz 频谱**，但不知道怎么用；本方案回答"怎么用" |
| 品牌 | **方案甲：保留海能达品牌外观**（用户已确认），不做白牌 |
| 主线 | 450MHz 不是容量层，是**覆盖与韧性层**；先由付费能力最强的行业客户锚定需求，再由运营商建一张网 |
| 交付形态 | 英文 PPT（22 页）+ 逐页英文演讲稿（写进 PPT 备注）+ 中文说明文档 |

### 五段式结构（听众能跟上的骨架）

| 段 | 页 | 内容 |
|---|---|---|
| **01** Why 450 MHz & Hytera | P1–P6 | 封面 · 国情 · **目录** · 450MHz 全球趋势 · 频段物理 · **MCS 是什么** |

## 三、给接手 AI 的关键提示

### 3.1 怎么改这个 PPT

**不要手改 PPTX。** 改 `03_生成脚本/build_ph450m_v7.py` 然后重跑。**仓库已可独立重建**（不再依赖 `F:\Workspace` 和外部模板）：缺省用 v7.pptx 自身当模板（脚本会清空全部页面，只复用母版、版式与 notesMaster），素材优先从 `05_素材库`、`06_用到的图片`、`03_生成脚本/素材/_recovered` 取。

```powershell
# 在仓库根目录；依赖：pip install python-pptx pillow pymupdf；预览需要 LibreOffice
# 1) 重新构建（缺省原地覆盖 01_交付物/菲律宾450M方案_v7.pptx）
python 03_生成脚本/build_ph450m_v7.py

# 2) 必须补这一步——重跑构建会清空全部备注（单页超 520 字符会告警）
python 03_生成脚本/ppt_notes.py 01_交付物/菲律宾450M讲稿_v7.md 01_交付物/菲律宾450M方案_v7.pptx

# 3) 出对外版（清空备注）
python 03_生成脚本/ppt_notes.py --strip 01_交付物/菲律宾450M方案_v7.pptx 01_交付物/菲律宾450M方案_v7_对外版.pptx

# 4) 刷新页面预览
python 03_生成脚本/render_preview.py 01_交付物/菲律宾450M方案_v7.pptx
```

2026-10-10 校验：沙箱重建结果与原 v7 逐形状比对 22 页 0 差异（改内容之前），说明重建链路可靠。`ppt_check.py` 不在本仓库，版面检查改用第 4 步渲染后目视。

### 3.2 脚本里的两个坑

1. **模板的 `notesMaster` 没有占位符**，python-pptx 因此建不出备注文本框。脚本已在保存前注入 `body` 占位符；**换模板要重新确认这一条**。
2. **保留模板页再加页会让 python-pptx 复用同名 part**，写出重名 zip 条目导致文件打不开。脚本已改为清空全部模板页后重建。

### 3.3 图片处理的两个坑（都踩过）

1. **透明底 PNG 不能走 JPEG 合成**。脚本里 `slim()` 会把 RGBA 合成白底，所以透明图必须走 `keepalpha()`——`fit()` 已改用它。搞错的话图标全变白方块。
2. **超大图要先缩**。脚本里 `slim()` 限 1600px、`keepalpha()` 限 900px，否则 PPTX 会涨到 40MB+。

### 3.4 设计规则（用户反复强调过的）

- **配色**：白底 `FFFFFF` + 卡片 `EEF2F9` + 海能达蓝 `0B308E` + 橄榄绿 `7F9B00` + 亮绿 `8CC63F`。**不要做成深色**（做过一版被否）。
- **每个元素都要说明一件事**。用户明确否掉过：底部拼贴横带、白底图标方块、漂浮装饰插画、无意义的天线塔图标。
- **导览页用插画，细节页用实拍**（用户明确要求）。
- **配图必须图文相关**。用户是逐张看图挑错的，放"意义不明"的图一定会被指出。
