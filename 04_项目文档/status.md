## 怎么重跑 v5（在项目根目录，三步不可换序，当前 14 页）

```powershell
# 1) 改版面或文字后重跑构建（整篇重建，封面到尾页）
python working\_gen\build_ph450m_v5.py 00_inbox\菲律宾解决方案包装.pptx deliverables\菲律宾450M方案_v5.pptx

# 2) 必须补这一步——重跑构建会清空全部备注
python 05_automation\python\ppt_notes.py deliverables\菲律宾450M讲稿_v5.md deliverables\菲律宾450M方案_v5.pptx

# 3) 版面检查（--quiet 只列出有问题的页码；退出码 1 表示有 error）
python 05_automation\python\ppt_check.py deliverables\菲律宾450M方案_v5.pptx --quiet
```

**顺序踩过两次坑（2026-10-10）**：一次是脚本缩进报错、构建根本没跑成，`ppt_notes.py` 把备注灌进了上一版稿子；一次是直接在 PowerPoint 里改了内容，重跑构建后手改部分被覆盖。所以：**不要手改 PPTX**，改文字改脚本、改讲稿改 md。

**改脚本时注意两个已知陷阱**：

1. 本模板的 `notesMaster` 一个占位符都没有，python-pptx 因此建不出备注文本框（`ppt_notes.py` 会报 `'NoneType' object has no attribute 'text'`）。脚本已在保存前补 `body` 占位符；**换模板要重新确认这一条**。
2. 保留模板页再加页，python-pptx 会复用同名 part（如 `slide17.xml`），写出重名 zip 条目导致 LibreOffice 拒绝打开。脚本已改为清空全部模板页后重建。

**`ppt_check` 的 60 条 warn 是已知误报，只看 error 数**：`WAVE` 是检查器按模板全局判定的（正文页挂「空白」版式，本身没有波浪），`INVISIBLE` 是浅灰卡片（`E9EDF3`）压白底的刻意设计。

**素材位置**：`working\_gen\素材\`——`_orig` 原稿内嵌图、`_case` 案例图、`_mcs` 平台截图、`_prod` 产品图、`_hi` 证书与双色调、`_cut` 单机裁图、`_ex` 配件图。双色调（尾页背景）有缓存，删掉会按 `duotone()` 自动重生。
